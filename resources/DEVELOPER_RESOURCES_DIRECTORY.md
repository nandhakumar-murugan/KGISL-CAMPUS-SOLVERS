## 📚 4. Git & Open Source Best Practices

* **Conventional Commits**: Use standardized commit prefixes:
  * `feat:` — A new campus solver feature or module
  * `fix:` — A bugfix or correction in syllabus data
  * `docs:` — Updates to documentation or setup instructions
  * `refactor:` — Code structure improvements without behavioral changes
* **Pair Programming Credit**: When building collaboratively, include the `Co-authored-by:` git trailer:
  ```git
  Co-authored-by: Contributor Name <contributor-email@users.noreply.github.com>
  ```
  *(This triggers the GitHub **Pair Extraordinaire (👥)** achievement for both contributors upon merge!)*
