# 🛠️ Free Google Developer Tools for KiTE Students

As a student at KGiSL Institute of Technology, you have access to powerful Google AI tools completely free of charge!

---

## 1. Google AI Studio (Free Gemini API Key)
* **Website**: https://aistudio.google.com/
* **Cost**: ₹0 (100% Free)
* **How to Get**:
  1. Go to [Google AI Studio](https://aistudio.google.com/) and sign in with your personal or college Gmail.
  2. Click **"Get API Key"** in the top left.
  3. Click **"Create API Key"** ➔ Copy your secret key!
  4. Use it in any Python script with pip install google-genai.

---

## 2. Google Colab (Free Cloud Python & GPUs)
* **Website**: https://colab.research.google.com/
* **Cost**: ₹0 (Run code directly in your browser without installing Python!)
