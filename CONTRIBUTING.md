# 🤝 Contributing to KGISL-CAMPUS-SOLVERS

Welcome! We are thrilled you want to contribute to the official open-source student initiative at KGiSL Institute of Technology.

Whether you are writing your first line of code, designing a flyer, or submitting past examination questions, **your contribution matters**!

---

## 🚀 How to Make Your First Contribution in 5 Simple Steps:

### Step 1: Fork this Repository
Click the **Fork** button at the top right of this GitHub page to create your own copy.

### Step 2: Clone Your Fork to Your Laptop
`ash
git clone https://github.com/<your-username>/KGISL-CAMPUS-SOLVERS.git
cd KGISL-CAMPUS-SOLVERS
`

### Step 3: Create a New Branch
`ash
git checkout -b feature/my-campus-contribution
`

### Step 4: Make Your Changes & Commit
Make your improvements (e.g. add a question paper, improve a prompt, fix documentation):
`ash
git add .
git commit -m "feat: add Semester 5 question paper answers for KiTE"
`

### Step 5: Push and Create a Pull Request (PR)
`ash
git push origin feature/my-campus-contribution
`
Go to the original repository on GitHub and click **"Compare & pull request"**!

---

## 🌟 Types of Contributions Welcomed:
1. **Code**: Add Python, JavaScript, or Streamlit features to any campus project.
2. **Notes & Syllabus**: Add verified question bank answers for KiTE autonomous courses.
3. **Bug Reports**: Open an Issue if something is broken.
4. **Campus Ideas**: Tell us what problem at KiTE we should solve next!

Thank you for building a smarter campus together! 🚀
