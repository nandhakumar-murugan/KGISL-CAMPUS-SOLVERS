# 🤝 Contributing to KGISL-CAMPUS-SOLVERS

Welcome! We are thrilled you want to contribute to the official open-source student initiative at KGiSL Institute of Technology.

Whether you are writing your first line of code, designing UI dashboards, improving documentation, or adding automated tests, **your contribution matters**!

> 📘 **New Contributor?** Read our detailed, step-by-step [Student Onboarding Guide](STUDENT_ONBOARDING_GUIDE.md) before you begin!

---

## 🚀 Quick Start: 5 Steps to Your First PR

### Step 1: Fork this Repository
Click the **Fork** button at the top right of this GitHub page to create your own copy.

### Step 2: Clone Your Fork Locally
```bash
git clone https://github.com/<your-username>/KGISL-CAMPUS-SOLVERS.git
cd KGISL-CAMPUS-SOLVERS
```

### Step 3: Create a Dedicated Branch
```bash
git checkout -b feat/my-campus-contribution
```

### Step 4: Make Your Changes & Commit
```bash
git add .
git commit -m "feat: add interactive prompt helper"
```

### Step 5: Push and Open a Pull Request (PR)
```bash
git push origin feat/my-campus-contribution
```
Go to your fork on GitHub and click **"Compare & pull request"**!

## 🌟 Types of Contributions Welcomed:
1. **Python & AI Code**: Add features, Streamlit UI, or Gemini API integrations across any subproject.
2. **Automated Testing**: Add `pytest` test suites to ensure zero bugs.
3. **Documentation**: Improve README files, code comments, and tutorials.
4. **Campus Problem Ideas**: Open an Issue proposing real campus challenges for our community to solve.
