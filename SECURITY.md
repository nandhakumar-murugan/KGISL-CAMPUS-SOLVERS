# Security Policy

The **KGISL-CAMPUS-SOLVERS** open-source initiative takes the security and integrity of student platforms, API keys, and campus services seriously.

## Supported Versions

| Version / Branch | Supported |
|---|---|
| `main` | :white_check_mark: |
| Active Feature Branches | :white_check_mark: |
| Deprecated Releases | :x: |

## Reporting a Vulnerability or Credential Leak

If you discover a security vulnerability, hardcoded API key, private student data exposure, or institutional credential within this repository:

1. **Do NOT open a public GitHub issue.**
2. Send an email immediately to the repository maintainer:
   - **Nandhakumar M**: `smnk2006@gmail.com`
3. Include the following details in your report:
   - Type of vulnerability / exposed resource
   - Exact file path and line number
   - Steps to reproduce or proof-of-concept
   - Impact assessment
4. You will receive an acknowledgment within **24 hours**, and remedial action (key revocation, commit sanitization, or hotfix) will be initiated promptly.

Thank you for helping keep our campus open-source community safe! 🛡️
