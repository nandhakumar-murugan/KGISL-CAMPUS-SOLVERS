Welcome to **KGISL-CAMPUS-SOLVERS**, an open-source engineering initiative led by the **Google Student Community at KGiSL Institute of Technology (KiTE)**.

Instead of writing toy classroom assignments, we build real-world, open-source software that directly solves the everyday academic and campus challenges students face across our departments (CSE, Cybersecurity, AI&DS, AIML, IT, CSBS, Mech, ECE).

## 🤝 3. How You Can Contribute (Anyone Can Join!):

You do **NOT** need to be an expert coder. There is a role for every single student at KiTE:

* 💻 **Coders**: Build Python scripts, create React/HTML frontends, write API connectors.
* 🌱 **Beginners / Learners**: Fix simple typos, format markdown files, test scripts, and learn Git with our mentors!
* 🎨 **Non-Coders & Designers**: Collect KiTE past question papers, summarize department syllabi, design UI mockups in Figma, report campus pain points.

👉 *Check out our [CONTRIBUTING.md](CONTRIBUTING.md) for a simple, 5-minute guide to making your first Pull Request!*
